## 🎯 Problem Statement
Creating AI generated images is usually locked behind paid tools with complex UIs. Students, designers, and content creators need a simple, free, and fast way to turn their ideas into images and manage them in one place.
Our project solves this by providing a clean web app where users can log in, generate images from text prompts, and manage their profile, history, and settings without any hassle.

## ✨ Key Features
### 1. Authentication Module - [Muhammad Shayan]
- Secure User Login / Signup
- Session Management
- Responsive forms using CSS Grid & Flexbox

### 2. AI Text-to-Image Generator - [Muhammad Ayan]
- Enter text prompt and generate AI images
- Real-time image preview
- Download generated images
- Clean UI with loading states

### 3. Settings Dashboard - [Muhammad Fasih]
- **Profile Edit**: Update name, email, profile picture
- **Image Resolution**: Select output resolution for generated images
- **History**: View all previously generated images with timestamps
